# Breast Cancer Segmentation using CAE and U-Net

This project presents a web-based mammogram image analysis system using Convolutional Autoencoder (CAE) and U-Net deep learning models. The models were trained and evaluated using the CBIS-DDSM dataset. The U-Net model is used for lesion segmentation, while the Convolutional Autoencoder (CAE) performs anomaly analysis through image reconstruction and reconstruction error. The application was developed using Streamlit to provide an interactive interface for mammogram image analysis.

## Framework

- Python
- TensorFlow
- Streamlit

## Models

- Convolutional Autoencoder (CAE)
- U-Net

## Dataset
